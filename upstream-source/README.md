# Original source snapshot

This directory preserves the original AIdea 3.6.1 TypeScript source for reference and license/source availability. It is not the already-patched 3.6.1.9 source tree. Running the upstream build here produces the upstream version.

The complete installed 3.6.1.9 plugin is in ../plugin/. Its JavaScript is readable bundled source. All differences from the original 3.6.1 XPI are recorded in ../patches/3.6.1-to-3.6.1.9.patch. The current separately maintained helper modules are in ../changes/. Repack the current plugin with ../tools/build_xpi.py.
